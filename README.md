# AQ Data Test P0 — 免费行情接口检测台

## 部署
将本 ZIP 解压后，把 `index.html` 和 `functions/probe.js` 按原目录结构上传至新的 GitHub 仓库，并在 Cloudflare Pages 连接该仓库。构建命令留空，输出目录设为仓库根目录（通常可填 `.`）。不要覆盖现有 AQ V38 站点。

## 运行
打开新站点，点击“开始一轮测试”。依次测试新浪（30只样本）、腾讯（3只样本）、东方财富（30只样本及接口报告总数）。在交易时段多次测试，记录成功率、耗时、错误。

## 限制
这只是连通性及小样本测试，不是全市场扫描，不验证交易所行情延迟或价格准确性，不包含任何付费密钥。若 Cloudflare Pages 未部署 functions，`/probe` 将无法使用。
